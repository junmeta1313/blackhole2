사진 클릭 → 확대 보기 · 사진 아래 [출처] → NASA 원본 자료

직접 사진 업로드는 체험 기능입니다. 추가한 사진은 다른 방문자에게 공유되지 않으며 새로고침하면 사라집니다.

마지막 추가 시간을 불러오는 중입니다…

이용 안내
  1. 사진을 누르면 큰 이미지와 제목·제공자를 볼 수 있습니다.
  2. 사진 아래 [출처]를 누르면 NASA 원본 자료가 새 창에서 열립니다.
  3. [새로운 관측 사진 전송]은 로그인 후 이용하는 업로드 체험입니다. [우주로 전송]을 누르면 이 화면에 사진이 추가됩니다.

자동 선별은 6시간 간격으로 예정되어 있습니다. 자료 추가 시각은 아래에 표시하며, 촬영 시각과는 다릅니다. 자동 실행 일정과 실제 추가 시간은 다를 수 있습니다.

상대성이론부터 우주 탐사까지, 관심 있는 주제로 글을 읽고 작성해보는 공간입니다.

글 제목 클릭 → 내용 보기 · 로그인 체험 후 [새 글 작성하기] → 글 작성

현재는 글쓰기·로그인 체험 기능입니다. 작성한 글은 이 화면에서만 유지됩니다.

이용 안내
  1. 목록의 글 제목을 누르면 게시글 내용을 볼 수 있습니다.
  2. 로그인 체험 후 [새 글 작성하기]를 눌러 제목과 내용을 입력하면 이 화면의 목록에 추가됩니다.
  3. 현재 작성한 글은 다른 방문자에게 공유되지 않으며 페이지를 새로고침하면 사라집니다.

우주 브리핑

원문 기반 AI 정리매일 최대 2건

NASA·ESA의 발표와 arXiv 논문을 수집하고, AI가 핵심 내용을 한국어로 정리합니다.

글에서 한국어 요약 읽기 · [원문 보기] → 출처 · [질문하기] → 해당 글에 관한 대화

마지막 추가 시간을 불러오는 중입니다…

이용 안내
  1. 각 글에는 출처, 기사·논문 구분, 한국어 요약이 표시됩니다. [원문 보기]로 원래 자료를 확인할 수 있습니다.
  2. [질문하기]를 누르면 해당 브리핑과 확보한 원문·웹 검색 자료를 참고하는 AI 대화창이 열립니다.
  3. 같은 IP에서는 모든 브리핑을 합쳐 1분에 한 번 질문할 수 있습니다. 답변은 공백 포함 500자 이내입니다.
  4. 질문과 답변은 페이지에 머무는 동안만 이어집니다. 페이지를 나가거나 새로고침하면 대화가 사라집니다.

매일 오전 9시 17분(한국시간)에 최대 2건을 자동 추가하도록 예정되어 있습니다. 운영자가 수동 실행하면 추가 글이 올라올 수 있습니다. 자동 실행 일정과 실제 추가 시간은 다를 수 있습니다.

창작 갤러리

AI 창작4시간마다 자동 생성

천체·색감·구도 등을 무작위로 조합해 AI가 새로운 우주 이미지와 관측 이야기를 만듭니다.

사진 클릭 → 확대 이미지와 이야기 · [상세정보] → 프롬프트·사용량·추정 비용

마지막 추가 시간을 불러오는 중입니다…

이용 안내
  1. 사진을 누르면 확대 이미지와 그 모습을 바탕으로 쓴 관측 이야기가 펼쳐집니다.
  2. 이미지와 관측 기록은 모두 창작입니다. 실제 천체·관측 데이터로 해석하지 마세요.
  3. 이야기 아래 [상세정보]를 펼치면 이미지 생성 프롬프트, 선택 조합, 토큰 사용량과 달러 기준 추정 비용을 볼 수 있습니다.
  4. 사용량이 남아 있지 않은 과거 작품은 기록 없음으로 표시됩니다.

4시간 간격으로 새 작품을 자동 생성하도록 예정되어 있습니다. 이미지 생성 후 설명글이 추가될 수 있으며 운영자가 수동으로 작품을 더할 수도 있습니다. 자동 실행 일정과 실제 추가 시간은 다를 수 있습니다.

Open Library 자료검색할 때 불러오기

Open Library의 도서 정보를 이용해 천문학·우주 탐사 관련 책을 찾아보는 서가입니다.

추천 책 클릭 또는 제목·저자·키워드 입력 → [검색] · 결과 제목 클릭 → 도서 정보

이용 안내
  1. 추천 책을 누르면 해당 도서를 검색합니다. 검색창에 제목·저자·우주 키워드를 직접 입력해도 됩니다.
  2. 언어를 선택한 뒤 검색하면 한국어 또는 영어 도서로 범위를 좁힐 수 있습니다.
  3. 검색 결과의 책 제목을 누르면 Open Library의 상세 페이지가 새 창에서 열립니다.
  4. 아래 화살표로 검색 결과 페이지를 이동할 수 있습니다. 표지가 없는 책은 표지 없음으로 표시됩니다.

책 정보는 검색할 때 불러옵니다. 정기적으로 새 게시글을 만드는 게시판은 아닙니다.

AI 토론

주제 직접 입력총 4~8회 선택

주제와 양측 입장을 정하면 두 AI가 각자의 입장과 근거를 발표한 뒤 번갈아 반박하고, 끝난 대화와 양측 요약을 공개 기록으로 남깁니다.

비밀번호·주제·입장 입력 → 횟수 선택 → [토론 시작] · 완료된 토론 제목 클릭 → 기록 열람

이용 안내
  1. 완료된 토론은 비밀번호 없이 읽을 수 있습니다. 목록에서 제목을 누르면 전체 대화와 양측 요약이 열립니다.
  2. 새 토론을 시작하려면 토론 비밀번호, 주제, ChatGPT와 Gemini의 입장을 입력하세요.
  3. 총 발언 횟수는 첫 입장 발표를 포함해 4~8회입니다. ChatGPT와 Gemini가 각각 입장·구체적인 근거·추가 관점을 한 번씩 발표하고, 세 번째 발언부터 서로 반박합니다. 4회를 선택하면 각 AI가 입장 발표 1번과 반박 1번씩 발언합니다.
  4. 각 발언은 준비 시작 후 최소 7초 뒤 표시됩니다. 입력중 표시가 켜져 있는 동안에는 답변을 준비하고 있습니다.
  5. 완료 전 페이지를 나가거나 새로고침하면 토론이 취소되고 게시글로 등록되지 않습니다.
  6. 오류로 멈췄다면 [계속하기]로 재시도할 수 있습니다. AI 주장의 근거는 원문 자료와 함께 확인해주세요.

비밀번호를 입력하면 토론을 시작할 수 있습니다. AI 호출 비용이 발생합니다.
